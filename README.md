# Responsive Pricing Table

A modern, responsive pricing page built using **HTML5 and CSS3** as part of the **Veda Technology Web Development Internship – Task 12**.

## 📌 Project Overview

This project presents three web hosting plans—Basic, Pro, and Business—in a clean, user-friendly interface. It includes monthly and yearly billing options, a highlighted popular plan, a detailed feature comparison table, and an expandable FAQ section.

## ✨ Features

- **Three Pricing Plans:** Basic, Pro, and Business.
- **Billing Options:** Monthly and yearly pricing with a displayed 20% discount.
- **Featured Plan:** Visually highlighted Pro plan.
- **Responsive Layout:** Designed to adapt to different screen sizes.
- **Feature Comparison:** Detailed table to compare plans.
- **Interactive FAQ:** Expandable questions and answers.
- **Modern UI:** Styled cards, visual hierarchy, and call-to-action buttons.
- **Accessibility:** Semantic HTML elements and descriptive labels.

## 🛠️ Technologies Used

- **HTML5** – Semantic structure and webpage content.
- **CSS3** – Layouts, styling, and responsive design.
